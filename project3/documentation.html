Documentation:

Idea

My idea for this project was to create an endless driving game, in which you control a car left and right
and collect gas cans inorder to gain points while avoiding oil spills that will cause you to 'spin out'
and lose.

Final Result

In the end I did create the project i set out to make, the car is controller left and right,
using the arrow keys, while jerry cans and oil spills randomly spawn and fall down towards the player
simulating a driving experince. I achieved this through various methods and a class that creates new objects
and causes them to move down every 'frame'. I also managed to create some collision detection between
the player and the objects. The objects also 'despawn' after a certain threshold.
I was also able to clamp the player onto the road so as they could not simple run off screen.
I created a death screen which allows the player to replay as well as see their score for that run.
Using local storage I was able to create a high score system that lets the know their best run points value.
